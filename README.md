# Jynae Myklebust — Technical Writing Portfolio

A sample documentation set and working prototype built around **Cimply**, a fictional scheduling and workflow product for creative teams. Everything here — the PRD, style guide, user guides, API reference, and case studies — was created to demonstrate real-world technical writing deliverables, paired with a lightweight prototype UI for context.

## What's inside

- **Prototype site** (`index.html`, `dashboards/`, `css/`, `js/`, `images/`) — mockups of Cimply's Scheduler and Designer dashboards.
- **`docs/`** — the writing samples: PRD excerpt, competitive briefs, case studies, quick start guide, user guide, release notes, style guide, and API reference (available as PDF and source Markdown).
