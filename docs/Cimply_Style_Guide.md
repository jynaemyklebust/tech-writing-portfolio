# Cimply Style Guide

> Writing sample — Cimply is a demonstration scheduling product for creative studios, built to showcase documentation skills. Not a live commercial product.

Quick reference for keeping Cimply documentation visually and terminologically consistent. Start new documents from `Cimply_Template.dotx` rather than rebuilding these settings by hand.

## Logo

Available files:

| File | Use |
|---|---|
| `CimplyLogo wtext.png` | Full wordmark with tagline. Cover pages or standalone brand placements — not running headers. |
| `CimplyLogosm no back.png` | Icon only, transparent background. Document headers and anywhere space is tight. |

**Usage rules**

- Don't recolor, stretch, or distort either file — use as provided.
- Keep clear space around the mark roughly equal to the height of the icon.
- Minimum display height: about 0.3 in (below that, the checkmark detail gets hard to read).

## Color Palette

| Name | Hex | Usage |
|---|---|---|
| Brand Purple | `#451771` | Document titles, primary logo mark |
| Accent Purple | `#732EB5` | Section headings (Heading 1) |
| Muted Gray | `#666666` | Disclaimers, italic secondary notes |
| Body Black | `#000000` | Body text (default, not explicitly set) |

## Typography

All styles use Times New Roman.

| Style | Size | Color |
|---|---|---|
| Title | 28pt | Brand Purple (`#451771`) |
| Heading 1 | 16pt | Accent Purple (`#732EB5`) |
| Body | 12pt | Black (default; no explicit color override needed) |
| Disclaimer / secondary notes | 12pt, italic | Muted Gray (`#666666`) |

## Terminology & Conventions

- Use "Designer," not "Freelancer," for the role that receives and completes orders — Designer is function-based and employment-status-agnostic, matching how "Scheduler" is named.
- Capitalize "Status" when referring to the field/label itself (e.g., "change the Status to Complete").
- Use curly quotes (' ' " ") and em dashes (—), not straight quotes or double hyphens.
- Every writing-sample doc opens with the italic gray disclaimer line shown at the top of this page, directly under the title.

## Starting a New Document

Create new Cimply docs from `Cimply_Template.dotx`. It already has the Title and Heading 1 styles set to the correct brand colors and the logo placed in the header, so new documents inherit the branding automatically instead of it being redone by hand each time.
